# Projection

Open a screen-sized drawing canvas. The compact toolbar has color, pen width, eraser, Clear All, background controls, media insertion and Return. Right-click switches between drawing and erasing.

With background enabled, the screen gets a darker dotted backdrop. With it disabled, the canvas stays transparent. Add images and videos using the same Finder, drop and Temporary File Shelf choices as Notes.

Clear All asks before removing drawings and inserted media from the canvas; original source files stay intact. Return goes back to the HUD. Escape dismisses a submenu first, then returns to the HUD.
