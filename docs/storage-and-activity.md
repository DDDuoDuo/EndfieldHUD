# Storage and Activity Monitor

## Storage

See total, used and available disk space. Refresh checks the readings again, and Storage Settings opens the system storage page.

## Activity Monitor

Overview shows CPU, RAM, network and disk activity graphs. Apps shows a sortable list of running applications with available usage readings. Scroll through the list and switch tabs without leaving the HUD.

Unavailable readings show a dash. These are monitoring tools; the HUD does not terminate apps or clean your disk from this section.
