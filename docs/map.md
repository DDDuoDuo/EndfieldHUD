# Map

Explore an offline terrain map with country outlines. Drag to pan, scroll or pinch to zoom, and use the zoom controls for smaller steps. Reset returns to 3× zoom.

Right-click to add a pin. Click a pin to cycle its marker style; right-click it again to delete it. Clicking the map dismisses the selected pin's coordinates. Country highlighting follows the map's center.

The map uses simplified terrain and boundaries for a decorative overview. It does not access your location or load street maps. Pins stay on this Mac.
