# Notes

Add text, a checklist, a picture/video or a drawing. Move and resize panels, enlarge them for editing, and pin them to keep them visible in other sections.

Text formatting appears while editing: font, size, color, bold, italic, underline and strikethrough. Drawing has color, pen width and eraser controls. Media can come from Finder, a drop or the Temporary File Shelf; videos have playback and progress controls.

Press Escape or Command-Return to finish text editing. Menus and text follow the HUD's tilt. Notes and imported media copies stay on this Mac; deleting a note does not delete its original source file.
