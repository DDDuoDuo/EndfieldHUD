# EndfieldHUD 1.0.1

- Added Traditional Chinese and Japanese throughout the interface. Language selection now uses the same animated list as display selection.
- Enlarged the menu-bar icon and removed the two older crystal/gem icon choices. Saved icon preferences remain compatible.
- Added English, Simplified Chinese, Traditional Chinese and Japanese READMEs, with installation, permissions, screenshots and animated previews using sample data.
- Improved localized label sizing and refreshing when switching languages.

## Install or update

Download **EndfieldHUD-1.0.1-macOS.dmg**, drag **EndfieldHUD.app** to **Applications**, eject the disk image, then open the installed app. The default summon hotkey is **Control + backtick**. Existing installed release copies can use **Check for Updates** in the menu bar or About. Your settings and saved data are retained.

The ZIP contains the same universal app. A source ZIP and SHA-256 checksums are included.

**Requirements:** Apple silicon/macOS 11+ or Intel/macOS 10.15.4+. Per-app volume requires macOS 14.2+ and System Audio Recording permission. Automatic Focus requires macOS 13+ and two user-created Shortcuts; see the README setup steps.

The app is ad hoc signed and **not Apple-notarized**. macOS may require its per-app **Open Anyway** approval. Live testing is on an M2 MacBook Air with macOS 15.7.4; other hardware and OS versions have not received equivalent live coverage.
