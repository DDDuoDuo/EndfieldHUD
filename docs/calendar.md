# Calendar

Browse months with the arrows or keyboard, click a day to see its events, and use Today to return to the current date. Add an event with a title, date and optional details. Select an existing event to edit or delete it.

Calendar keeps its own local events; it does not read or change macOS Calendar. With notification permission, reminders are scheduled for 09:00 on the previous day and the event date. An event added later on its date can get a near-immediate reminder. Refresh retries reminder setup.

Events are date-only. Up to 30 upcoming and 256 total events are supported. macOS notification and Focus settings affect delivery.
