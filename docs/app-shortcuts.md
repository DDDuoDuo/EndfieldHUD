# Windows 应用中心

## 入口与布局

- 默认保留原 HUD 槽位：存储在下方，应用在右方。设置 → 显示 → “互换存储与应用位置”可即时互换，默认关闭，重启保留，恢复显示默认设置时关闭。
- HUD 右侧默认只提供统一的“应用”入口，不单独列出快捷方式或分组。
- 页面上方固定“总览”，后面是自定义分组；点击分组直接切换下方网格，不进入二级页面。
- 总览展示全部快捷方式，按实际目标与启动参数去重。分组栏过长时，在分组栏上滚动鼠标滚轮横向浏览，总览保持固定。
- 方形卡片使用浅色半透明叠层、双边框和原应用图标；双击启动；应用打开时，在 HUD 任意位置点击鼠标右键直接关闭，包括图标、外围空白和已展开的操作菜单。

## 添加与编辑

- 右上角仅保留“操作”菜单，包含新建分组、添加应用、编辑／完成、删除、分组调整和刷新。添加支持 `.exe`、`.lnk`、`.url` 和已安装的打包应用；支持拖入或粘贴快捷方式。
- 总览添加的项目先不归入分组；在分组中添加的项目自动加入该分组。
- 编辑模式可拖拽快捷方式或分组标签调整顺序，单击切换多选，单击空白处取消选择；在操作菜单中删除或完成。
- 进入编辑时，名称框默认编辑当前分组，无需额外选择。选中单个快捷方式时可重命名该快捷方式；点击空白处恢复编辑当前分组。总览不能重命名或删除。
- “编辑／完成”统一放在操作菜单中，“删除当前分组”删除当前分组；操作 → 选择多个分组可批量选择并删除，操作 → 选择快捷方式切回。
- 编辑快捷方式时，操作菜单可将选中项添加到其他分组、移至其他分组，或为单个项目重新选择目标。
- 总览顺序、各分组内部顺序、分组顺序分别保存，重启恢复上次选择的分组。

## 删除范围

- 分组内删除：只移除当前分组成员关系，总览及其他分组保留。
- 总览删除：从全部分组及总览移除；自动读取的桌面项目会被记为隐藏，避免重新导入。
- 删除分组：保留其中快捷方式在总览中；当前分组被删除后切回总览。
- 多选删除作为一次原子存储操作；确认框明确说明范围。
- 不移动、不修改、不删除桌面原文件，也不卸载应用。

## 自动读取桌面与性能

- 启动后读取当前用户桌面和公共桌面的 `.lnk`、`.url`，通过 Windows Known Folders 获取实际位置，支持重定向桌面。
- 后续使用 Windows Shell 文件变更通知；没有周期性目录轮询。检查与写入在现有后台串行执行器上运行。
- 未变化的文件复用检查结果，图标仍使用有界缓存与现有网格可见区域加载机制。
- 刷新保留用户修改的名称、分组和排序；同一目标与参数的多个桌面链接合并为一个项目。
- 操作菜单提供“刷新桌面快捷方式”和“恢复已移除的桌面快捷方式”。
- 桌面原链接删除后：纯自动导入且未分组的项目消失；已经分组的项目保留并标记失效，可重新选择目标。
- 目录读取失败不视为清空桌面；单个链接读取失败保留已有条目。

## 数据兼容

Windows 快捷方式文件升级为 version 2，包含统一的项目列表、每个分组有序的 `itemIDs`、上次选择的分组以及桌面来源和隐藏记录。
读取 version 1 时自动将旧 `groupID` 和重复项目转换为成员引用；第一次写入之前保留 `shortcuts-v1-backup.json`。旧版程序拒绝写入 version 2，避免破坏多分组数据。未知字段及导入的 Mac 定位信息继续保留。

分组分类栏沿用剪贴板缓存的深色底栏、黄色渐变选中块、底部强调线和主题文字颜色，保留横向滚动、分组拖拽与多选。应用网格滚轮步幅为原来的两倍，使用平滑过渡；图标仅在跨行或切换分组时更新需求，未变化的卡片图标不重复生成内容。

- 应用网格每行 6 个，原始应用图标保留，图标加载按紧凑网格可见区域更新。
- 设置 → 显示 → 模块包含快捷方式管理的“应用”，支持隐藏、上下移动和在 HUD 右侧拖拽排序；互换布局后该行显示“存储”，沿用该右侧槽位的顺序和显示设置。
- 原项目影像加工模块保持完整；固定资源清单换行，避免 Windows 检出时触发哈希校验失败。
